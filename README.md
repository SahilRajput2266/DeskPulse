## 🌟 Overview

**DeskPulse** is a lightning-fast, real-time customer support platform designed for high-velocity software engineering teams. 

It unifies inbound customer inquiries into a reactive live queue, tracks sub-minute **SLA response deadlines** with live countdown timers, provides rapid-fire **canned response snippets**, and synchronizes live conversation threads between support engineers and customers over WebSockets.

---

## 🚀 Key Features

* **⚡ Real-Time In-Thread Chat:** Synchronous WebSocket message delivery with zero page refreshes.
* **⏱️ Dynamic SLA Countdown Timers:** Visual target counters with automated warning alerts when response windows narrow.
* **📋 Rapid Canned Snippets:** 1-click insertion of verified technical templates, refund protocols, and status updates.
* **🏷️ Priority & Status Triage:** Instant transitions across Open, In Progress, and Resolved with live queue count badges.
* **🧪 1-Click Inbound Simulator:** Dispatch simulated enterprise tickets to stress-test your team's support workflows.

## ⚡ Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/SahilRajput2266/DeskPulse.git
cd DeskPulse
npm install
```

### 2. Run Locally
```bash
npm start
```

Open your browser at:
```
http://localhost:5250
```
